# Weft

**WEFT** — World-building, Era, and Fantasy Timeline。

一个**没有边界**的小说辅助写作工具。

---

## 设计理念

大多数写作工具默认你的故事是关于"人"的，时间线是公历的，世界是现实的。Weft 不做这些假设。

**主角可以是任何东西。** 人物、街区、王朝、一把刀、一场台风——任何在时间中存在（或被时间穿过）的东西，都是 [moai](moai.md)。你定义它，给它一个时间锚点，它就成为故事的主角。

**时间由你定义。** 格里高利历只是参考。你可以写公历 `[2020, 1, 1, ...]`，也可以定义自己的历法——十天一旬、三旬一月、四月一年的幻想世界，照样能进位、能算偏移。时间引擎是[一组可替换的砖块](phase.md)。

**事件是漂流水。** 故事就是实体（moai）被事件（[drift](drift.md)）穿过的过程。你把事件扔进时间线，后端自动算出每个实体在事件发生时的状态——年龄、阶段、任何你想算的东西。

三条线交汇处就是故事：

```
实体 (moai) ── 谁在时间中存在？
事件 (drift) ── 发生了什么？
时间 (phase/aqueduct) ── 用谁的历法、按什么规则？
```

没有一个维度是预设的。这就是 Weft 的"无边界"——它不帮你做世界观的假设，它给你搭脚手架，你决定世界观是什么。

## 名字

变量名不是乱取的——它们来自同一个隐喻：

**道（dao）。** 子在川上曰："逝者如斯夫，不舍昼夜。"时间是一条河，万物在其中流逝。`dao.py` 是数据的源头，故事从这里流入系统。

**水（drift）。** 事件是河面上漂流的片段——来去无定，被时间推着走。每一段 drift 都是一个故事节点，在时间线上漂流。

**石（moai）。** 河里有石头，水流过石头，石头留在原地。实体被事件穿过，却不为事件所动——就像复活节岛的摩艾石像，沉默伫立，看潮起潮落。叫 "stone" 太平凡，摩艾石像是完美的意象。

**渠（aqueduct）。** 水需要渠道才能流到该去的地方。历法就是引水渠——你把事件之水倒进去，它把水引到时间线上正确的位置。渠可以换，水还是那水。

```
道 (dao) ── 万物流逝的河
渠 (aqueduct) ── 引导水流的渠道（历法）
水 (drift) ── 漂流的事件
石 (moai) ── 伫立水中、被水穿过的实体
```

## 快速开始

```bash
# 安装依赖
uv sync

# 启动（后端 + 前端）
cargo tauri dev -- tests/guojing.yml

```

---

## 项目结构

```
weft/
├── weft_backend/     # Python 领域层与 PyTauri commands
│   ├── commands.py   # Tauri IPC commands
│   ├── dao.py        # 数据模型与 YAML 解析
│   ├── aqueduct.py   # 时间运算引擎
│   ├── material.py   # 派生属性计算（如星座）
├── weft-frontend/    # Tauri React + Vite 前端
│   ├── app/          # React 页面
│   └── components/   # 组件
├── src-tauri/        # Rust/Tauri 桌面壳
└── tests/            # 测试数据与端到端测试
```
