# 页面布局分析

## 当前组件结构
1. Home.tsx
   - 功能：应用首页
   - 特点：无导航栏，使用min-h-screen确保全屏高度
   - 布局：flex布局，内容居中

2. RiverTabs.tsx  
   - 功能：带导航栏的主界面
   - 特点：包含顶部导航栏，使用flex布局
   - 布局：h-full + flex-1实现高度自适应

3. Footer.tsx
   - 功能：全局页脚
   - 特点：fixed定位固定在底部
   - 内容：显示当前绑定文件路径

## 需求匹配
1. 导航栏差异：通过路由区分Home/RiverTabs
2. Footer固定：已实现
3. 高度自适应：需要调整布局结构
4. 组件关系：App.tsx应作为布局容器
